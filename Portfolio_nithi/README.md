## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/subathrarajakumar60-netizen/Subathra_portfolio.git
   cd Subathra_portfolio
   ```

2. **Open directly in browser**:
   - Simply double-click `index.html` to open it in any web browser.
   - Or start a local server using Python:
     ```bash
     python -m http.server 8080
     ```
   - Open [http://localhost:8080](http://localhost:8080) in your browser.

---

## 🌐 Deploy to GitHub Pages

1. In your GitHub repository, navigate to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Choose branch: **`main`**, folder: **`/ (root)`**, and click **Save**.
4. Your website will be live at:
   `https://subathrarajakumar60-netizen.github.io/Subathra_portfolio/`
